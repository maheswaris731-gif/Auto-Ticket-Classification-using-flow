# Auto Ticket Classification using Flow Designer

## Overview
This repository contains the documentation and implementation steps for the **Auto Ticket Classification using Flow Designer** project in ServiceNow. The goal is to automate the ticket categorization and assignment process to reduce manual effort and improve resolution efficiency.

---

## Business Requirements

The ServiceNow implementation must satisfy the following key requirements:

1. **Automated Ticket Classification:** Automatically classify incoming IT tickets based on the issue description provided by the user.
2. **Zero Manual Intervention:** Assign both **Category** and **Subcategory** dynamically without requiring manual input.
3. **Dependent Choice Logic:** Implement and support dependent choice logic between Category and Subcategory fields.
4. **Email Notification:** Automatically send a confirmation email notification to the caller immediately upon ticket creation.
5. **Standardized Data Storage:** Store all ticket information in a structured, standardized, and consistent format.
6. **Scalability & Maintenance:** Ensure the system architecture allows easy maintenance, updates, and future scalability.
